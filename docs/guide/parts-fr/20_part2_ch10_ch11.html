Partie IIGraphiques 3D

Introduction aux graphiques 3D

ModelViewer peut représenter des données qui n'ont rien à voir avec un solveur. Un tableau de nombres - mesures, export d'un tableur, fonction mathématique - devient une surface, une courbe, un nuage de points, un ensemble de barres, un volume ou un champ de flèches, dans la même scène 3D que vos modèles, avec la même caméra, les mêmes outils de sélection, de coupe, d'annotation et d'export d'images, et le même éclairage. C'est une façon de regarder des données dans l'espace, pas un tableur ni un logiciel de statistiques : il n'y a ni édition des données, ni ajustement, ni flux de données en direct.

Ce que vous obtenez dans la scène

  • Chaque graphique est une entrée de l'arbre de la scène avec sa propre case de visibilité ; il peut donc être masqué ou affiché comme un modèle.
  • Une boîte d'axes encadre les graphiques, avec des étiquettes, des graduations et des nombres ; des plans de référence (XY, XZ, YZ) sont disponibles. Tous les graphiques d'un document partagent un même jeu d'axes (chapitre 15).
  • Une légende de couleurs apparaît pour les graphiques colorés selon une valeur.
  • Un graphique peut être modifié plus tard : changez les données, les colonnes ou les formules et reconstruisez-le sur place (chapitre 17).
  • Les graphiques sont enregistrés dans la session .mvf avec leurs données, et les graphiques de points et de lignes s'exportent aussi en glTF, GLB et OBJ (chapitre 17).
Remarque

Les graphiques sont des vues d'analyse. Ils sont dessinés de la même façon dans tous les modes de rendu et ne sont pas dessinés par le lanceur de rayons. Pour obtenir une image rendue d'un graphique, utilisez l'export d'images normal du visualiseur.

Tracer un fichier CSV

À quoi doit ressembler le tableau

L'entrée est un tableau en texte brut : des lignes de nombres séparés par un séparateur, généralement avec une ligne d'en-tête qui nomme les colonnes. Tout tableur ou outil d'analyse peut l'écrire. La boîte de dialogue accepte la virgule, le point-virgule et la tabulation comme Séparateur, et La première ligne contient les noms de colonnes indique si la première ligne est un en-tête. Un petit exemple, le début de surface_ripple.csv (z = sin(r)/r sur une grille de 21 x 21 ; la dernière colonne répète z comme valeur de couleur) :

x,y,z,value
-5.0000,-5.0000,0.100248,0.100248
-5.0000,-4.5000,0.063807,0.063807
-5.0000,-4.0000,0.018686,0.018686
...
  • Les nombres utilisent le point décimal. Des cellules vides ou non numériques dans une colonne numérique rendent le tableau inutilisable ; la ligne d'état indique la ligne concernée.
  • Pour une ligne, l'ordre des lignes compte (c'est l'ordre le long du chemin) ; pour les autres types, non.
  • Le tableau peut être ouvert depuis un fichier (Ouvrir un CSV...) ou collé (Coller) ; après le chargement, les 200 premières lignes sont affichées dans un tableau d'aperçu, et la ligne d'état indique combien de lignes et de colonnes ont été lues.

La boîte de dialogue Ajouter un graphique 3D

  1. Ouvrez Visualisation → Graphique 3D... (ou Ajouter un graphique 3D... dans l'onglet Graphique 3D).
  2. Source des données : Fichier CSV ou données collées. Ouvrez ou collez votre tableau ; vérifiez le séparateur et le réglage de l'en-tête.
  3. Type de tracé : choisissez le type (chapitre 12). Les choix de colonnes ci-dessous s'adaptent à lui.
  4. Associez les colonnes : les colonnes de position X, Y, Z et, selon le type, Valeur de couleur, U, V, W, Base, Largeur, Profondeur. Le choix (aucune) omet une association. Le programme devine des colonnes plausibles d'après les noms de l'en-tête, et vous pouvez les modifier : l'association se fait par position dans le tableau, l'ordre des colonnes dans le fichier est donc une commodité, pas une exigence.
  5. Aperçu montre le graphique dans la scène avant son ajout - même taille, mêmes couleurs et même comportement que le graphique final - et Effacer l'aperçu le retire. Fermer la boîte de dialogue retire aussi un aperçu.
  6. Créer le graphique ajoute le graphique à la scène. Un Titre le nomme.

La valeur de couleur

Les graphiques de surface, de ligne, de nuage de points et de barres sont colorés selon une valeur. Par défaut, c'est la hauteur (Z) ; associez Valeur de couleur à une autre colonne pour colorer selon autre chose - le numéro de groupe d'un nuage de points, la vitesse le long d'un chemin. La couleur d'un nuage de points est par point ; celle d'une surface est interpolée entre ses sommets.

Quand le tableau est inutilisable

La ligne d'état sous l'aperçu indique ce qui a été lu et, si le tableau est inutilisable, pourquoi : une ligne avec du texte là où un nombre est nécessaire (elle nomme la ligne), un tableau qui n'est pas une grille régulière complète là où il en faut une (elle indique combien de lignes manquent), ou une colonne qui n'a pas été choisie. Le bouton Créer le graphique reste désactivé tant que le problème n'est pas corrigé. L'annexe C énumère les messages.

Astuce

Commencez avec un exemple du type souhaité (annexe A) et regardez ses colonnes, puis donnez la même forme à votre propre tableau. Un nouveau fichier est aussi simple qu'une ligne d'en-tête et des lignes de nombres.
