Part II3D plotting

Introduction to 3D plotting

ModelViewer can plot data that has nothing to do with a solver. A table of numbers - measurements, an export from a spreadsheet, a mathematical function - becomes a surface, a curve, a cloud of points, a set of bars, a volume or a field of arrows, in the same 3D scene as your models, with the same camera, selection, section, annotation and image-export tools, and the same lighting. It is a way to look at data in space, not a spreadsheet or a statistics package: there is no data editing, no fitting, and no live data feed.

What you get in the scene

  • Every plot is an entry in the scene tree with its own visibility checkbox, so it can be hidden or shown like a model.
  • An axes box frames the plots, with labels, tick marks and numbers; reference planes (XY, XZ, YZ) are available. All plots of a document share one set of axes (chapter 15).
  • A colour legend appears for plots coloured by a value.
  • A plot can be edited later: change the data, columns or formulas and rebuild it in place (chapter 17).
  • Plots are saved in the .mvf session with their data, and point and line plots also export to glTF, GLB and OBJ (chapter 17).
Note

Plots are analysis views. They are drawn the same way in every rendering mode and are not drawn by the ray tracer. If you want a rendered picture of a plot, use the normal viewer's image export.

Plotting a CSV file

What the table must look like

The input is a plain-text table: rows of numbers separated by a delimiter, usually with a header row that names the columns. Any spreadsheet or analysis tool can write it. The dialog supports the comma, the semicolon and the tab as the Delimiter, and First row contains column names says whether the first line is a header. A small example, the start of surface_ripple.csv (z = sin(r)/r over a 21 x 21 grid; the last column repeats z as the colour value):

x,y,z,value
-5.0000,-5.0000,0.100248,0.100248
-5.0000,-4.5000,0.063807,0.063807
-5.0000,-4.0000,0.018686,0.018686
...
  • Numbers use the decimal point. Empty or non-numeric cells in a numeric column make the table unusable; the status line names the row.
  • For a line the row order matters (it is the order along the path); for the other types it does not.
  • The table can be opened from a file (Open CSV...) or pasted (Paste); after loading, the first 200 rows are shown in a preview table, and the status line reports how many rows and columns were read.

The Add 3D Plot dialog

  1. Open Visualization → Plot 3D... (or Add 3D Plot... in the 3D Plot tab).
  2. Data source: CSV file or pasted data. Open or paste your table; check the delimiter and the header setting.
  3. Plot type: pick the type (chapter 12). The column choices below change to match it.
  4. Map the columns: the position columns X, Y, Z, and, as the type needs, Colour value, U, V, W, Base, Width, Depth. A choice of (none) leaves a mapping out. The program guesses sensible columns from the header names, and you can change them: the mapping is by position in the table, so the order of columns in the file is a convenience, not a requirement.
  5. Preview shows the plot in the scene before it is added - the same size, colours and behaviour as the final plot - and Clear Preview removes it. Closing the dialog also removes a preview.
  6. Build Plot adds the plot to the scene. A Title names it.

The colour value

Surface, line, scatter and bar plots are coloured by a value. By default it is the height (Z); map Colour value to another column to colour by something else - the cluster number of a scatter plot, the speed along a path. A scatter plot's colour is per point; a surface's is interpolated between its vertices.

When the table cannot be used

The status line below the preview says what was read and, if the table cannot be used, why: a row with text where a number is needed (it names the row), a table that is not a complete regular grid where one is required (it says how many rows are missing), or a column that was not chosen. The Build Plot button stays disabled until the problem is fixed. Appendix C lists the messages.

Tip

Start with a sample of the type you want (Appendix A) and look at its columns, then shape your own table the same way. A new file is as easy as a header line and rows of numbers.
