Fills, notes, images and probing

Fills: ribbons and curtains

Lines and scatter plots can be filled with a translucent ribbon, coloured like the plot, to a base plane or between two curves.

GoalHow
A curtain under a lineLine / Curve (line_helix.csv): tick Fill to Base Z and set the base (0). Edit Plot to change the base; the curtain hangs from the line where it lies below the base.
A band between two curvesLine / Curve with a second Z column (line_band.csv: columns x, y, z, z2, value): tick the fill and choose the column in or between the line and column. The band pinches to a line where the curves cross. The base box is unused while a column is chosen; with the column set to (none) the fill reaches the base plane again.
Ribbons from scatter pointsScatter (scatter_clusters.csv): Fill to Base Z with a base such as -3; or a column in or between the plot and column (scatter_band.csv) for ribbons between two sets of points.
Fill a generated curveParametric curve, Helix preset: Fill the curve down to Base Z, or type a second z2(t) (for example 2 + sin(t)) in or up to z2(t) = to fill between two curves with the same x(t), y(t). Whether a generated plot is filled is decided when it is built.

The axes box always grows to include what the fill reaches.

Text notes

A note is a short text at a point of your data - a peak, an outlier, a threshold. Select a plot and open the Text notes group in the 3D Plot tab.

  • Place note arms a click tool: click a point on the plot. The click snaps to the nearest data point of a visible plot (within 14 pixels; for lines, also the closest point on a segment), otherwise it uses the surface point under the cursor. A box asks for the text, which may have several lines. Add at centre adds a note at the centre of the plot's data.
  • In the view, drag a note to move it, double-click to edit it, right-click to delete it. The table in the tab edits the note's X, Y, Z and text directly.
  • Notes are stored in the plot's data coordinates, so they stay on their point when the axis scale changes. They follow the plot's visibility, are drawn even when the axes box is hidden, and are saved with the session.
  • Every placement, move, edit and deletion can be undone.

Section curves on hover

For a surface, tick Show section curves on hover. Moving the cursor over the surface draws, through the hovered point, the curves where the X, Y and Z planes cut it - coloured red, green and blue like the axes (the blue one is the contour line through the point) - together with the point's data values. Only the connected curve through the point is drawn, so a saddle shows one branch. It is a quick way to read a profile of a surface without building a chart, and it works in the single view only.

Images on a plane

An image can stand on one of the plot planes: a site map under a surface, a photograph of a specimen beside its measured data. Choose Data source Image on a plane, pick the file, and choose the plane: XY (flat, at the Z minimum), XZ or YZ (upright, at the minimum of the remaining axis); the ranges adapt to the picture's shape when you pick it or change the plane, and you can adjust them.

  • Opacity (100 % by default) lets what is behind the picture show through; a picture with its own transparency combines with it (image_gradient_alpha.png fades towards its corners).
  • Seen from behind, a picture reads mirrored. For an opaque picture, tick Readable from behind and the back shows it the right way round (image_gradient.png has an "L" mark to show which way round it is). The option is available only for an opaque picture at 100 % opacity - with a transparent area or a lower opacity both sides would show through each other, so the back stays mirrored.
  • An image plot takes no colour map or legend: its pixels are its colour.

Editing, saving and exporting

Editing a plot

Every plot remembers how it was made. Select it in Active plot and click Edit Plot...: the dialog reopens on the same source with the table, the column choices, the expressions, the ranges, the sample counts and the parameters restored. Change what you need and click Rebuild Plot: the plot is rebuilt in place, with no new tree entry, and keeps its title, visibility, colour map, range and bands, reference planes, contour lines, line width and axes settings (with Automatic colour range on, the range follows the new data). What cannot change in an edit is the data source (and, for a formula surface, the surface/contour choice); build a new plot for that.

Saving

Plots are saved in the .mvf session with everything needed to edit them later: the data, the definition (columns or expressions), the axes, the colour settings and the notes. After reopening, Edit Plot... still works. A session saved by an older version that had different axes for each plot opens on the selected plot's axes, now shared.

Exporting

  • Point and line plots (scatter markers, lines, pathline trails) export to glTF, GLB and OBJ with the rest of the scene; their colours are baked into the file so other programs show them coloured.
  • Surfaces, bars and other mesh plots export like any mesh.
  • Images of the view - for reports, slides, papers - come from the program's image export and the PDF report, like any other view.
  • Plots are not drawn by the ray tracer, and path-traced renders do not contain them. The animation of pathlines and the notes' on-screen drawing are viewing aids and are not part of an exported model.
Tip

To get your numbers back out, keep the CSV: a plot's definition is saved, but the original table remains the master copy. If you generate data from a script, rerun it, reopen the plot with Edit Plot... and load the new table.
