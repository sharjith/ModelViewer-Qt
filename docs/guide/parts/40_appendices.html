Sample file catalogue

The samples ship in sample-models/Simulation and sample-models/Plot3D; each folder has a README.txt that describes every file and how it was made. Values in the generated files are synthetic: they test the program, not physics.

Messages and troubleshooting

What you may see, and what to do

SituationCause and remedy
A format is missing from the Open dialogYour build lacks the library for it (NetCDF for Exodus, CGNS, HDF5 for VTKHDF and MED). Help → About shows what is enabled.
"A simulation result is already being loaded"Only one result loads at a time; wait for the progress bar or cancel it.
The result opens grey, with no coloursThe file has no fields (only geometry). The panel says so.
Numbers have no unit in the legendThe file does not state one. Choose it under Quantity and Values are in.
Values look wrong by a factor of 1000 or 1,000,000The unit of the file differs from what you assumed (Pa and MPa; mm and m). Check the units of the analysis and set them.
Colours differ between steps or between resultsThe range is per step or per result. Use Automatic (all steps), a Custom range, or Same colour range for both.
"This result has no displacement field"It cannot be shown deformed; the file has to contain displacements.
Sections, iso-surfaces, streamlines or volume do nothingThe result has no volume cells (a shell), or the selected field is not a node field (streamlines need a node vector field). The info line under the group says which.
Iso-surfaces are hiddenSwitch on a clipping plane and switch off Colour the Clipping Plane cut with the field: an opaque cut hides what is behind it.
"Cut faces and iso-surfaces are shown as they were saved (frozen)"The session was saved without the volume. Save with Also store the volume to keep them live.
No tensor to choose for the ellipsoidsThe result has no six-component field with stress in its name.
A chart is empty or one dotA one-step result shows its history as a point; a click that missed the result gives no data.
Compare button unavailableThe document needs two results; compare ends by itself if one is hidden or closed.
Plot: "Open or paste tabular data first"The CSV has not been loaded.
Plot: a table that is not a complete gridA surface or pathline table must have every grid combination once; the message says how many rows are needed.
Plot: "Unknown variable", "Division by zero", "log requires a positive value"Fix the expression; Build Plot stays disabled until it evaluates everywhere in the range.
Plot: an axis went back to LinearA Log 10 axis cannot show a plot whose values reach zero; every plot returned to Linear with it. Use SymLog, or remove that plot.
A picture appears mirroredYou see the back of an image plane. Tick Readable from behind (opaque pictures only) or look from the front.
Glass or other effects are missing in the plotPlots and results are drawn flat in every mode and are not ray traced.

Glossary

Boundary surface
The faces of a solid result that belong to exactly one cell: the skin that is drawn.
Cell data
A field with one value per element, drawn flat (also: element data).
Contour
A line (or band edge) of equal value.
Derived field
A value computed from another field, such as von Mises stress from a stress tensor.
Displacement
The vector by which a node moved under load; the basis of the deformed shape.
Field
A quantity defined over the model: scalar, vector or tensor.
Iso-surface
The surface in a volume where a field has one constant value.
Lazy loading
Reading a step from the file only when it is shown, so memory does not grow with the number of steps.
Mode shape
The pattern of movement of a structure vibrating at a natural frequency; its amplitude is arbitrary.
Node data
A field with one value per mesh point, interpolated smoothly.
Pathline
The track of a particle carried by a field that changes with time.
Principal stress
One of the three normal stresses in the orientation where the shear stress vanishes.
Quiver
A plot of arrows, one for each point of a vector field.
Snapshot
The data a saved session keeps of a result: the surface, the chosen fields and steps, units and view state.
Step
One state of a result: a load increment, a time step or a mode.
Streamline
The path along a vector field frozen at one moment.
SymLog
An axis scale that is logarithmic for large values and linear near zero, so it can show negative numbers.
Tensor glyph
A symbol (here an ellipsoid) whose shape and size show a tensor.
Von Mises stress
A single equivalent stress derived from the full stress tensor, used to judge yielding of ductile materials.
