Probing and charts

Colours tell you where a value is high or low; a chart tells you how much, and how it changes. ModelViewer reads values straight from the result and plots them without leaving the program.

Reading a single value

Move the mouse over the model: the value of the shown field at the cursor appears next to it, in the displayed unit. On a node field the value is interpolated at the cursor; on a cell field it is the value of the element under the cursor (or the averaged value, if Average cell data to nodes is on).

The four charts

ChartHow to start itShows
Plot Over TimeRight-click a point on the result → Plot Over Time Here; or the Plot Over Time... button, then click a pointThe history of the shown field at that point, over all steps. For a modal result the x axis is the frequency of each mode.
Plot Over LinePlot Over Line..., then click two pointsThe field along the straight line (chord) between the two points, at the current step.
DistributionDistribution...A histogram of the field over the whole result: how much of the model is at low, middle and high values.
Added curvesRight-click inside a chartMore points of the model, or your own data from a CSV file, on the same axes.
  • The point history reads the value at the clicked point of the volume or, for a shell result, at the closest point of the surface. The chord of a Plot Over Line follows the surface of a shell; where the chord leaves a curved shell the curve has a gap.
  • A chart of a cell field uses the averaged values; a result with one step shows its history as a single dot.
  • Plot Over Time Here is not available while two results are being compared (chapter 8).

Adding your own data

A chart can carry measurements, a response curve or another analysis next to the simulated curve. The CSV needs two columns, x then y, and a header row that names the curve. A header of the form Name (unit) gives the curve a unit: if that unit is the same as the main curve's, both share the y axis; if it differs - a temperature next to a stress - the curve is drawn against a second y axis on the right. A curve whose header has no unit shares the main axis.

SampleUse
thermal_probe_test.csvSynthetic "thermocouple" readings (time, temperature) for the middle of the far face of FEM_box_thermal_transient.frd. Open the result, plot over time at that face, add the CSV, play: the cursor travels along both curves. The clicked point is not exactly the sample's, so the curves are close, not identical.
FEM_box_modes_frf.csvA synthetic frequency-response curve with peaks at the six mode frequencies of FEM_box_modes.frd. Plot over time on any point, add the CSV, and click a peak: the result jumps to that mode.
Tip

An exported chart CSV can be added back to a chart later with Add curve from CSV... - handy for comparing two analysis runs on one chart, because the header carries the unit.

Comparing results

The usual reasons to open two results are two designs, before and after a change, a static run against a vibration mode, or two load cases. Comparing them needs the results side by side, seen from the same viewpoint, with colours that mean the same thing. Compare does exactly that.

Setting up a comparison

  1. Put both results in one document: open the first with File → Open... and add the second with Visualization → Simulation Results → Add Result to This Document.... Both keep their true file coordinates, so two results of the same model coincide, which is why compare draws them in separate panes.
  2. In the Simulation Results tab choose the other result in Compare with and click Compare (or use Visualization → Simulation Results → Compare Results...). The viewport splits into two panes, each drawing one result with its own legend. Show in chooses side by side or stacked (top and bottom).
  3. Tick Same colour range for both: equal colours then mean equal values in both panes. Without it each result uses its own range.
  4. Tick Link the cameras to keep both views in step: rotating, panning or zooming one does the same in the other.
  5. Click Exit Compare (the same button) to return to the single view.

What works in compare mode, and what does not

  • Compare shows two different results of the document; the same result cannot be compared with itself. Each pane has its own legend, headed with the result's name.
  • Orbit, pan, zoom and the standard views work. Same colour range for both joins the ranges of the two results, and is only available while both show the same unit.
  • The timeline drives the active result only, the one chosen in the Result box.
  • While compare is on, selection by clicking, the hover highlight and the hover value readout, and the clipping-plane gizmos are switched off, and Plot Over Time Here is not available. The measurement and annotation tools are not pane-aware yet. Ray tracing is off.
  • Fit to screen still fits the whole window, so a wide model can be wider than its pane: zoom out a little.
  • Compare ends by itself when either result is hidden, closed or removed (also by undo). The layout is not saved in a session.
  • Compare holds both results in memory at once, so two very large results need twice the memory (chapter 9).
Caution

Compare shows two results next to each other; it does not compute the difference between them (there is no A minus B field). To read numbers out of two analyses, chart the same point of each and put both on one chart (chapter 7), or compare the hover values one result at a time.

A good pair to try

ibeam_cantilever.frd (bending) and ibeam_torsion.frd (torsion) are the same I-beam under different loads: add one to the other's document, turn on the deformed shape and the shared colour range, and set the last load step.
