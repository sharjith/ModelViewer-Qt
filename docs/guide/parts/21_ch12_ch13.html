The plot types

This chapter is the reference for what each plot type needs and offers. The columns are mapped in the Add 3D Plot dialog; the styling controls named here are in the 3D Plot tab (chapter 15).

Surface and contour

A surface needs z over x and y. When the rows form a complete regular grid (every combination of the x values and the y values exactly once, in any row order), the grid is meshed directly. Otherwise the points are triangulated, which is what surface_scattered.csv tests: fourteen irregular points with a gently sloped height.

  • Contour lines adds iso-lines of Z to any surface: On the surface draws dark lines on it (visible from both sides), On the base plane draws colour-mapped lines flattened onto the floor of the axes box. Contour levels sets how many.
  • The separate Contour (surface iso-lines) type shows the lines only, and Project contours onto the base plane flattens them.
  • Colour bands turns the smooth colour of the surface into discrete bands; a fixed colour range is available too.

Line / curve

Row order is the order along the curve (line_helix.csv: two turns of a helix). The colour follows Colour value (or Z) along the curve. The Line width is in screen pixels. A line can be filled to the base plane or to a second curve (chapter 16).

Scatter

One marker per row; Marker size sets the size. Colours are per point, not interpolated: scatter_clusters.csv has three clusters coloured by their id. Variants:

  • Draw stems to Base Z: a thin line from each point down (or up) to the base value.
  • Show error bars (±Z) with an error column: a vertical bar of ± that size at each point (scatter_error_bars.csv).
  • Fill to Base Z: a translucent ribbon from each point to the base plane, or, with a column chosen in or between the plot and column, to a second set of Z values (scatter_band.csv). The axes box grows to include both.

Bar and histogram

  • The height is Z. Base, Width and Depth are optional; without them bars start at 0 and use a width and depth of 0.8, which leaves a gap between neighbouring bars. A bar below its base extends downward, so signed data works (bar_signed.csv).
  • Colour value defaults to the height.
  • One-dimensional histogram (bar_histogram_1d.csv: columns bin and count): set X to the bin column, Y to (none), Z to the count, and leave the rest (none). The result is one row of equal bars centred on Y = 0, with height and colour both driven by the count.
  • Bar width and Bar depth can be changed later in the tab.

Voxel / volumetric

Map X, Y and Z to the grid indices and the colour value to the occupancy (voxel_sphere.csv: a sphere carved from a 9 x 9 x 9 grid, with occupancy fading from 1.0 at the centre to 0.15 near the shell). Zero occupancy is transparent and non-zero values fade in by occupancy, so the plot is a soft cloud rather than a set of boxes.

Vector (quiver)

Each row is a point and a vector. quiver_vortex.csv is a rigid rotation about the Z axis plus a small upward component: arrows curl around Z and lengthen with distance. Arrow size in the tab sets the length scale without growing with the camera; arrow colour follows the value (the legend reads Vector magnitude).

Plots from formulas

You do not need a file to make a plot: a formula, a parametric definition or a preset generates the data. The sources share the CSV plots' preview, colour, axes, notes and export tools, and a generated plot remembers its definition so it can be edited and rebuilt (chapter 17).

A mistake is reported in the status line under the preview, by name: Unknown variable: q, Missing closing parenthesis, Division by zero, log requires a positive value. Build Plot stays disabled until the expression evaluates. Examples:

Formula surface   z =  a*exp(-((x-x0)^2+(y-y0)^2)/(2*s^2))        (Gaussian preset)
Parametric curve  x = cos(t)   y = sin(t)   z = t/(2*pi)            (a helix)
Implicit surface  f = x^2 + y^2 + z^2 - r^2                         (a sphere of radius r)

Preview, build and edit

Refresh Preview evaluates the formula and shows the plot in the scene, with a status line such as Pathlines from 12 seeds over t = 0 ... 10 (n segments), coloured by time. Build Plot adds it. Later, select the plot in Active plot, click Edit Plot...: the dialog reopens on the same source with the expressions, ranges, sample counts and parameters restored; change one and click Rebuild Plot. The plot updates in place, keeping its title, visibility, colours and axis settings. The source type cannot be changed in an edit; build a new plot for that.

Tip

Generated plots are a fast way to check a data pipeline or to build a picture with no data at hand: a Gaussian bump as a target, a saddle to show a minimum-maximum, a torus as a test object for the surface tools.
