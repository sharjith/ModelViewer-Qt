# Forklift (not included)

The tutorial lessons 26-28 and tutorial videos 1, 4 and 10 use the model "Forklift" by Madana
(GrabCAD Community Library, 25 August 2020): https://grabcad.com/library/forklift-92

The GrabCAD page states no licence, and GrabCAD's terms give other users a licence only for their own non-commercial, internal use. The model is
therefore **not redistributed** with ModelViewer. To follow those steps, download the STEP file from the link above (a free GrabCAD account is needed)
and open it with File > Open. Every step also works on `Skate-Board-Assy`.
