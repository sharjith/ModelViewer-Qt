Lesson 24: 3D Plots from Formulas, Fills, Images and Notes

Introduction

You do not need a file to make a plot. A formula can generate a surface, a curve, a vector field or the flow of a particle; fills turn lines and points into ribbons and curtains; an image can stand on a plane; text notes label what matters; and all the plots in a document share one set of axes, which can be logarithmic.

Formula Surfaces

Step 1: Choose a formula source
In the Add 3D Plot dialog set Data source to Formula surface. Preset offers Plane, Saddle, Paraboloid, Cone, Gaussian, Sinc Ripple, Wave, Mexican Hat, Bivariate Normal, Logistic Regression and Rosenbrock; the z = box holds the expression in x and y, and the ranges and sample counts set the grid.
Step 2: Preview and build
Click Refresh Preview after changing an expression or a parameter, then Build Plot. If the expression is wrong, for example an unknown variable, the status line names the problem and Build stays disabled.

The same dialog also has Parametric surface (Torus, Ellipsoid, Mobius Strip, Klein Bottle, Superellipsoid, Helicoid, Catenoid, Enneper Surface, Spherical Harmonic), Parametric curve (Helix, Lissajous, Trefoil Knot, Viviani Curve, Damped Spiral; the parameter is called t), Implicit surface and Formula vector field.

Editing a Generated Plot

Plots from formulas remember the definition they were built from. Select one in Active plot, click Edit Plot..., change an expression, a range or a parameter, and click Rebuild Plot: the existing plot updates in place and keeps its title, visibility, colours and axes settings. The source type cannot be changed in an edit - build a new plot for that.

Fills: Ribbons and Curtains

A line or a scatter plot can be filled to a base plane or between two curves. Fills are translucent and coloured like the plot.

Images on a Plane

An image can stand on one of the plot planes - a site map under a surface, a scan beside a model. Set Data source to Image on a plane, pick an image file, choose the plane (XY flat at the Z minimum, XZ or YZ upright) and set the ranges; they adapt to the picture's shape when you pick it. Opacity lets what is behind show through. Seen from behind a picture reads mirrored - for an opaque picture, tick Readable from behind.

Try image_gradient.png (320 x 200, with an "L" mark in one corner - it shows whether the picture is mirrored) and image_gradient_alpha.png, whose own transparency combines with the opacity setting. Readable from behind is only available for an opaque picture at 100 % opacity.

Text Notes

Step 1: Place a note
Select a plot, open the Text notes group in the 3D Plot tab and click Place note, then click a point on the plot - or use Add at centre.
Step 2: Edit and move it
Drag a note to move it, double-click to edit its text and right-click to delete it. Everything can be undone.

Notes are drawn at their data point inside the axes box, follow the plot's visibility and are saved with the session.

Shared Axes and Non-Linear Scales

All plots in a document are drawn on one set of axes. Under Axes in the 3D Plot tab you set each axis' label, Axis scale (Linear, Log 10 or SymLog), range and tick count. Changing a scale re-lays out every plot together: lines, scatter, surfaces, bars, arrows and voxel grids all follow it.

Step 1: Build two plots
Build scatter_error_bars.csv as a Scatter plot, then line_growth.csv as a Line / Curve (z = 10^(x/2), from 1 to 100).
Step 2: Set Z to Log 10
In Axes set the Z Axis scale to Log 10. Both plots re-lay out together: the exponential line becomes straight and the scatter moves with it.
Step 3: Meet the limit
A Log 10 axis needs the data of every plot to be above zero. Building line_helix.csv, which reaches 0, while Z is Log 10 returns Z to Linear with a status message; trying to set Log 10 with such a plot present is refused with a message naming the reason. SymLog handles any data, including negative values.
Screenshot: tutorial_24_log_axis_shared.png (700x450)
A scatter plot and an exponential line sharing a logarithmic Z axis
Vector arrows are re-aimed by the local stretch of the scale at their site and keep their length and colour; voxel grids are resampled; the hover readout of a surface still shows the plot's data values, not positions on the scaled axes. Switching back to Linear restores everything.
