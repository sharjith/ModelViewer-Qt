Lesson 28: Analysis, Selection and Scenes

Introduction

This lesson covers the tools that help you check a design and work through a large model: colouring surfaces to find problems, reading mass properties, selecting parts by what they are rather than where they are, and saving the state of a scene so you can return to it in one click.

Surface Analysis

Tools → Surface Analysis... colours the selected meshes by a quality measure. Pick an analysis, read the colours against the legend and use Show Readout on Hover to print the value under the cursor. Clear Overlay removes every analysis colour.

AnalysisWhat it shows
Draft AngleThe angle of every face against a chosen pull direction - can the part be released from a mould?
Zebra StripeReflected stripes: kinks in the stripes reveal where surfaces meet with less than smooth continuity.
Mean CurvatureHow strongly and in which sense the surface curves at each point.
Wall-ThicknessThe thickness of the walls, with an option to highlight walls thinner than a limit. Methods: Inscribed sphere, Local thickness (rays) and Normal ray (fast).
DeviationHow far a mesh is from a reference mesh - for comparing a scan with its CAD model.

Analysis colours replace the usual material look until you click Clear Overlay. If a surface looks oddly coloured later, that is the first thing to check.

Mass Properties

Tools → Mass Properties... lists the volume, mass and centre of gravity of every mesh and of every material. The density comes from the material's Physical Properties tab, so set it there first. The table can be searched and sorted; the row menu has Show Only, and selecting a row selects that mesh in the viewer. Open (shell) surfaces use a shell thickness instead of a volume.

Selecting by What Parts Are

The Selection menu has tools for large assemblies, where clicking one part at a time is slow:

  • Lasso selects everything inside a freehand outline.
  • Filter by Material and Filter by Color select every mesh that uses a material or a colour.
  • Filter by Bounding Box shows a draggable box gizmo and selects the parts inside it.
  • Named selection sets save a selection under a name so you can recall it later.
  • The Material Eyedropper / Brush picks the material of one mesh and paints it onto others.

Scene States

A scene state stores a named snapshot of the scene: the camera, which meshes are visible, the selection and the presentation settings. Choose Selection → Save Scene State... and give it a name; the States panel in the document dock lists every state and recalls it in one click. Use them for the views you return to - an overview, a cutaway, a detail with parts hidden.

Step 1: Set up a view
Hide the parts you do not want, select the ones you want to emphasise and position the camera.
Step 2: Save it
Choose Selection → Save Scene State..., type a name such as Gearbox only and confirm. Make a second state from a different view.
Step 3: Recall it
Click a state in the States panel: the camera, visibility, selection and presentation return in one step.
