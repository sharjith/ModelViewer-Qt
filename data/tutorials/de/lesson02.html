Lektion 2: Modelle öffnen

Einführung

ModelViewer unterstützt eine große Vielfalt an 3D-Dateiformaten. Lernen wir, wie Modelle in die Anwendung geöffnet und importiert werden.

Unterstützte Dateiformate

  • Mesh-Formate: OBJ, STL, PLY, glTF (.gltf, .glb), FBX, 3DS, DAE (Collada), Blender (.blend) und viele weitere über die Assimp-Bibliothek
  • CAD-Formate: STEP (.stp, .step), IGES (.igs, .iges), BREP (.brep) über die OpenCASCADE-Bibliothek
  • Natives Format: MVF (.mvf) - das eigene Format von ModelViewer zum Speichern kompletter Szenen

Methode 1: Über das Menü

Der Standardweg zum Öffnen von Dateien:

Schritt 1: Datei → Öffnen klicken
Gehen Sie in der Menüleiste zum Menü „Datei“ und klicken Sie auf „Öffnen“, oder drücken Sie Strg+O
Screenshot: tutorial_02_file_menu.png (300x250)
Das Menü „Datei“ mit hervorgehobenem Eintrag „Öffnen“
Schritt 2: Ihre Datei auswählen
Ein Dateidialog erscheint. Navigieren Sie zu Ihrer 3D-Modelldatei und wählen Sie sie aus.
Screenshot: tutorial_02_file_dialog.png (600x400)
Der Dateidialog mit verschiedenen 3D-Dateiformaten
Schritt 3: Das Laden abwarten
Das Modell wird geladen, ein Fortschrittsbalken zeigt den Status. Bei großen Dateien kann dies einen Moment dauern.
Screenshot: tutorial_02_loading_progress.png (500x150)
Fortschrittsbalken beim Laden eines Modells
Sie können den Ladevorgang abbrechen, indem Sie in der Statusleiste auf „Laden abbrechen“ klicken.

Methode 2: Ziehen und Ablegen

Der schnellste Weg, Dateien zu öffnen:

Schritt 1: Ihre Datei finden
Suchen Sie die 3D-Modelldatei in Ihrem Dateimanager (Windows-Explorer, Finder, Nautilus usw.)
Schritt 2: In das Fenster ziehen
Ziehen Sie die Datei einfach an eine beliebige Stelle im ModelViewer-Fenster und legen Sie sie dort ab.
Screenshot: tutorial_02_drag_drop.png (600x400)
Vorführung: eine 3D-Datei wird per Drag-and-drop in das ModelViewer-Fenster gezogen
Sie können mehrere Dateien gleichzeitig ziehen und ablegen. Jede wird in einer neuen Sitzung geöffnet.

Methode 3: Zuletzt verwendete Dateien

Zuletzt verwendete Dateien schnell wieder öffnen:

Schritt 1: Das Menü „Zuletzt verwendet“ öffnen
Gehen Sie zu Datei → Zuletzt verwendet..., um eine Liste der zuletzt geöffneten Dateien zu sehen.
Schritt 2: Datei auswählen
Klicken Sie auf eine beliebige Datei in der Liste, um sie sofort zu öffnen.
Screenshot: tutorial_02_recent_files.png (400x300)
Das Menü „Zuletzt verwendet“ mit der Liste zuvor geöffneter Modelle

Weitere Modelle importieren

Sie können Modelle zu einer vorhandenen Szene hinzufügen:

Schritt 1: Datei → Importieren verwenden
Klicken Sie auf Datei → Importieren oder drücken Sie Strg+I
Schritt 2: Modelle auswählen
Wählen Sie eine oder mehrere Dateien aus, die Ihrer aktuellen Szene hinzugefügt werden sollen.
Schritt 3: Modelle werden kombiniert
Die neuen Modelle werden Ihrem Modellbaum hinzugefügt und erscheinen im Ansichtsfenster.
Screenshot: tutorial_02_multiple_models.png (700x450)
Ansichtsfenster mit mehreren importierten Modellen, der Modellbaum zeigt alle Einträge
Verwenden Sie Importieren, wenn Sie mehrere Modelle in derselben Szene bearbeiten möchten. Verwenden Sie Öffnen, wenn Sie mit einem neuen Modell neu beginnen möchten.

Progressives Laden

Bei großen Dateien verwendet ModelViewer progressives Laden:

  • Objekte erscheinen, sobald sie geladen sind
  • Sie können mit bereits geladenen Objekten arbeiten
  • Der Fortschrittsbalken zeigt den Gesamtfortschritt
  • Sie können jederzeit abbrechen
Nach dem Öffnen einer Datei rahmt das Ansichtsfenster das Modell automatisch mit „Alles einpassen“ ein, damit Sie es vollständig sehen. Drücken Sie jederzeit F, um alle Objekte einzupassen.
