Leçon 2 : Ouvrir des modèles

Introduction

ModelViewer prend en charge une grande variété de formats de fichiers 3D. Voyons comment ouvrir et importer des modèles dans l'application.

Formats de fichiers pris en charge

  • Formats de maillage : OBJ, STL, PLY, glTF (.gltf, .glb), FBX, 3DS, DAE (Collada), Blender (.blend) et bien d'autres via la bibliothèque Assimp
  • Formats CAO : STEP (.stp, .step), IGES (.igs, .iges), BREP (.brep) via la bibliothèque OpenCASCADE
  • Format natif : MVF (.mvf) - le format propre de ModelViewer pour enregistrer des scènes complètes

Méthode 1 : par le menu

La manière habituelle d'ouvrir des fichiers :

Étape 1 : Cliquer sur Fichier → Ouvrir
Allez dans le menu Fichier de la barre de menus et cliquez sur Ouvrir, ou appuyez sur Ctrl+O
Capture d'écran: tutorial_02_file_menu.png (300x250)
Le menu Fichier avec l'option Ouvrir en surbrillance
Étape 2 : Sélectionner votre fichier
Une boîte de dialogue de fichier apparaît. Naviguez jusqu'à votre fichier de modèle 3D et sélectionnez-le.
Capture d'écran: tutorial_02_file_dialog.png (600x400)
La boîte de dialogue de fichier avec différents formats de fichiers 3D
Étape 3 : Attendre le chargement
Le modèle se charge et une barre de progression indique l'état. Pour les gros fichiers, cela peut prendre un moment.
Capture d'écran: tutorial_02_loading_progress.png (500x150)
Barre de progression pendant le chargement d'un modèle
Vous pouvez annuler le chargement en cliquant sur le bouton « Annuler le chargement » de la barre d'état.

Méthode 2 : glisser-déposer

La manière la plus rapide d'ouvrir des fichiers :

Étape 1 : Repérer votre fichier
Trouvez le fichier de modèle 3D dans votre explorateur de fichiers (Explorateur Windows, Finder, Nautilus, etc.)
Étape 2 : Glisser vers la fenêtre
Faites simplement glisser le fichier et déposez-le n'importe où dans la fenêtre de ModelViewer.
Capture d'écran: tutorial_02_drag_drop.png (600x400)
Démonstration du glisser-déposer d'un fichier 3D dans la fenêtre de ModelViewer
Vous pouvez glisser-déposer plusieurs fichiers à la fois. Chacun s'ouvre dans une nouvelle session.

Méthode 3 : fichiers récents

Rouvrez rapidement les fichiers sur lesquels vous avez travaillé récemment :

Étape 1 : Accéder au menu Récents
Allez dans Fichier → Récents... pour voir la liste des fichiers ouverts récemment.
Étape 2 : Sélectionner le fichier
Cliquez sur n'importe quel fichier de la liste pour l'ouvrir immédiatement.
Capture d'écran: tutorial_02_recent_files.png (400x300)
Le menu Récents avec la liste des modèles ouverts précédemment

Importer des modèles supplémentaires

Vous pouvez ajouter des modèles à une scène existante :

Étape 1 : Utiliser Fichier → Importer
Cliquez sur Fichier → Importer ou appuyez sur Ctrl+I
Étape 2 : Sélectionner les modèles
Choisissez un ou plusieurs fichiers à ajouter à votre scène actuelle.
Étape 3 : Les modèles sont combinés
Les nouveaux modèles sont ajoutés à votre arbre du modèle et apparaissent dans la vue.
Capture d'écran: tutorial_02_multiple_models.png (700x450)
Vue avec plusieurs modèles importés et l'arbre du modèle affichant tous les éléments
Utilisez Importer lorsque vous voulez travailler avec plusieurs modèles dans la même scène. Utilisez Ouvrir lorsque vous voulez repartir de zéro avec un nouveau modèle.

Chargement progressif

Pour les gros fichiers, ModelViewer utilise le chargement progressif :

  • Les objets apparaissent au fur et à mesure de leur chargement
  • Vous pouvez interagir avec les objets déjà chargés
  • La barre de progression indique l'avancement global
  • Vous pouvez annuler à tout moment
Après l'ouverture d'un fichier, la vue cadre automatiquement le modèle avec « Tout ajuster » pour que vous le voyiez en entier. Appuyez sur F à tout moment pour ajuster tous les objets à la vue.
