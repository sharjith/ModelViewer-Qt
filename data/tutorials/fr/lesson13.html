Leçon 13 : Optimisation des performances

Introduction

Travailler avec de gros modèles nécessite des stratégies d'optimisation. Voici comment conserver des performances fluides même avec des scènes complexes.

Comprendre les performances

Plusieurs facteurs influencent la vitesse de rendu :

  • Nombre de polygones : plus de polygones signifie un rendu plus lent.
  • Mode d'affichage : le mode réaliste est nettement plus lent que Ombré ou Fil de fer.
  • Nombre d'objets : un grand nombre d'objets augmente la charge système.
  • Taille des textures : les grandes textures consomment plus de mémoire et de bande passante GPU.
  • Complexité de l'éclairage : les ombres et l'éclairage basé sur l'image (IBL) sont coûteux en calcul.
  • Résolution d'écran : les résolutions plus élevées nécessitent de calculer davantage de pixels.

Optimisations automatiques

ModelViewer comprend des fonctions intégrées pour aider à gérer les performances :

Étape 1 : Aperçu basse résolution
Pour les modèles de plus de 50 Mo, une version simplifiée est automatiquement affichée pendant la navigation (rotation, déplacement, zoom). Le détail complet revient lorsque le mouvement s'arrête.
Étape 2 : Chargement progressif
Les gros fichiers se chargent progressivement, ce qui vous permet de commencer à travailler avant que le modèle soit entièrement chargé.
Étape 3 : Élimination hors champ (frustum culling)
Les objets situés en dehors du champ de vision actuel de la caméra ne sont pas rendus, bien qu'ils restent en mémoire.

Stratégies d'optimisation manuelle

Techniques que vous pouvez utiliser pour améliorer la réactivité :

Étape 1 : Changer de mode d'affichage
Utilisez le mode Ombré ou Fil de fer pendant la modélisation ou la transformation. Gardez le mode réaliste pour les revues finales.
Classement des performances (du plus rapide au plus lent) : Fil de fer > Ombré > Ombré avec fil de fer > Réaliste.
Étape 2 : Masquer les objets inutiles
Masquez les objets sur lesquels vous ne travaillez pas. Les objets masqués ne sont pas rendus, ce qui libère des ressources GPU. Utilisez « Afficher seulement » pour isoler des composants dans de grands assemblages.
Étape 3 : Réduire la qualité des ombres
Dans les réglages d'Environnement, abaissez la qualité des ombres (Ultra → Élevée → Moyenne → Faible) ou désactivez complètement les ombres pendant les travaux lourds.
Étape 4 : Désactiver l'IBL/les reflets
Désactivez l'éclairage basé sur l'image et les reflets d'environnement lorsqu'ils ne sont pas strictement nécessaires à la tâche en cours.
Étape 5 : Utiliser la projection orthographique
La projection orthographique est légèrement plus rapide que la perspective, ce qui la rend idéale pour le travail technique.

Optimisation des réglages

Configurez la qualité de rendu globale :

Étape 1 : Niveau de MSAA
Dans Modifier → Paramètres → Rendu, réduisez les échantillons MSAA (anticrénelage) (8x → 4x → 2x → Désactivé) si la fréquence d'images est mauvaise.
Étape 2 : Filtrage anisotrope
Réduisez le niveau de filtrage (16x → 8x → 4x → 2x) pour diminuer la charge de traitement des textures.

Travailler avec de gros fichiers

Stratégies pour les modèles massifs :

  1. Importer sélectivement : si possible, n'importez que les pièces dont vous avez besoin.
  2. Utiliser des versions à faible nombre de polygones : conservez des versions low-poly distinctes pour le travail de modélisation actif.
  3. Travailler par sections : utilisez les plans de coupe pour vous concentrer sur une seule zone à la fois et ne rendre que celle-ci.
  4. Attendre le chargement : laissez les fichiers se charger complètement avant de lancer une interaction lourde.
  5. Fermer les sessions inutilisées : chaque fenêtre de visualisation ouverte consomme des ressources système.

Gestion de la mémoire

Surveillez et gérez les ressources système :

Étape 1 : Indicateurs de mémoire
Surveillez la barre d'état pour les avertissements d'utilisation de la mémoire.
Étape 2 : Supprimer les objets inutilisés
Supprimez définitivement les objets dont vous n'avez pas besoin plutôt que de simplement les masquer, car les objets masqués occupent toujours de la RAM et de la VRAM.
Étape 3 : Tailles des textures
Utilisez des textures de taille appropriée ; les textures 4K sont souvent inutiles pour de petits objets. Envisagez des textures 2K ou 1K pour de meilleures performances.

Liste de contrôle des performances

En cas de ralentissement, essayez ceci dans l'ordre :

  1. Passez au mode d'affichage Ombré ou Fil de fer.
  2. Masquez les objets dont vous n'avez pas besoin pour le moment.
  3. Désactivez temporairement les ombres.
  4. Désactivez l'IBL et les cartes d'environnement.
  5. Abaissez le réglage MSAA dans les Paramètres.
  6. Utilisez la projection orthographique.
  7. Fermez les sessions de visualisation inutiles.
  8. Réduisez la taille des textures.
  9. Envisagez de travailler avec une version à moins de polygones.
Dans les cas extrêmes (plus de 100 millions de polygones), envisagez de scinder le modèle en fichiers séparés ou d'utiliser un logiciel de CAO dédié pour les travaux de géométrie les plus lourds.
