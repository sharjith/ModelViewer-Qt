Leçon 6 : Modes de caméra

Introduction

Les modes de caméra changent la façon de se déplacer dans l'espace 3D. ModelViewer propose trois modes de caméra distincts, conçus chacun pour un usage différent.

Changer de mode de caméra

Étape 1 : Au clavier
Appuyez sur 1 pour Orbite, 2 pour Vol ou 3 pour le mode Première personne.
Étape 2 : Avec la barre d'outils
Cliquez sur le bouton « Modes de caméra » de la barre d'outils d'affichage et choisissez dans le menu.
Capture d'écran: tutorial_06_camera_menu.png
Menu déroulant des modes de caméra avec les options Orbite, Vol et Première personne
L'icône du bouton de la barre d'outils se met à jour pour indiquer le mode de caméra actif.

Mode Orbite (touche : 1)

Idéal pour : examiner des objets, travail de CAO, inspection générale de modèles.

Commandes de la souris
• Glisser avec le bouton central : pivoter autour du modèle
• Glisser avec le bouton droit : déplacer la vue
• Molette de la souris : zoom avant/arrière
Commandes du clavier
• W/S : déplacer vers le haut/bas
• A/D : déplacer vers la gauche/droite
• X/Z : zoom avant/arrière
• I/K : tangage (haut/bas)
• J/L : lacet (gauche/droite)
• M/N : roulis

Mode Vol (touche : 2)

Idéal pour : explorer de grandes scènes, visites architecturales, navigation sur terrain.

Commandes du clavier
• W/S : avancer/reculer
• A/D : se déplacer latéralement à gauche/droite
• Q/E : descendre/monter (altitude)

Mode Première personne (touche : 3)

Idéal pour : navigation au niveau du sol, simulations de marche, intérieurs architecturaux.

Commandes du clavier
• W/S : avancer/reculer
• A/D : se déplacer latéralement à gauche/droite
• Q/E : descendre/monter (altitude)
