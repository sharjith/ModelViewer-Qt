Leçon 14 : Conseils et flux de travail

Introduction

Cette dernière leçon présente des conseils utiles, des raccourcis et des flux de travail professionnels qui vous rendront plus productif dans ModelViewer.

Conseils de navigation

  • Perdu dans l'espace ? Appuyez sur F pour ajuster instantanément tous les objets à la vue.
  • Déplacement rapide vers un point : cliquez avec le bouton central (sans glisser) pour recentrer la vue sur un point précis.
  • Zoom vers la souris : le zoom à la molette se concentre sur la position actuelle du curseur.
  • Inertie douce : les gestes rapides de la souris créent un mouvement inertiel fluide pour un visionnage agréable.
  • Arrêter le mouvement : cliquez sur n'importe quel bouton de la souris pour arrêter instantanément le mouvement inertiel.

Astuces de sélection

  • Désélection rapide : appuyez sur Échap pour effacer toutes les sélections en cours.
  • Rechercher des objets : utilisez la zone de recherche au-dessus de l'arbre du modèle pour filtrer les éléments par nom ; elle correspond aussi aux noms des assemblages et des nœuds racines, pas seulement aux maillages feuilles.
  • Centrer sur la sélection : clic droit → « Centrer l'écran » pour cadrer uniquement les objets sélectionnés.
  • Faire défiler jusqu'à la sélection : clic droit → « Centrer la liste d'objets » pour faire défiler automatiquement l'arbre jusqu'à l'élément sélectionné.

Flux de travail de visibilité

  • Focalisation rapide : sélectionnez des pièces et appuyez sur Maj+Espace pour les isoler immédiatement.
  • Comparer des variantes : masquez une conception, travaillez sur une autre, puis utilisez Alt+S pour inverser la visibilité et comparer les deux.
  • Révélation progressive : masquez tous les objets, puis affichez les groupes un par un pour comprendre peu à peu les assemblages complexes.

Conseils de caméra et de vue

  • Changement rapide de caméra : appuyez sur 1, 2 ou 3 pour changer instantanément de mode de caméra.
  • Vues standard : utilisez les boutons de la barre d'outils pour des vues instantanées Haut, Avant ou Gauche.
  • Vue de présentation : combinez la vue isométrique, la projection en perspective et le mode réaliste.
  • Vue technique : utilisez la vue de face, la projection orthographique et le mode ombré.
  • Vue d'analyse : utilisez le mode Fil de fer ou Ombré avec fil de fer pour inspecter la topologie du maillage.

Flux de travail des matériaux

  1. Commencez par des couleurs de base en mode Ombré.
  2. Passez en mode réaliste pour voir le rendu PBR.
  3. Ajustez les valeurs de métallique et de rugosité pour définir les types de surface.
  4. Ajoutez des textures (albédo, normales, rugosité) pour le détail.
  5. Activez l'IBL (éclairage basé sur l'image) pour l'éclairage d'environnement final.
  6. Affinez l'exposition et le mappage tonal pour l'aspect final.

Flux de travail professionnels

Inspection d'assemblages mécaniques

  1. Ouvrez l'assemblage en mode multi-vues.
  2. Utilisez des plans de coupe pour voir les composants internes.
  3. Activez Ombré avec fil de fer pour voir clairement les limites des pièces.
  4. Utilisez « Afficher seulement » pour isoler des sous-systèmes précis en vue de leur étude.

Visite architecturale

  1. Passez en mode caméra à la première personne (3).
  2. Activez l'IBL avec un environnement HDRI architectural.
  3. Activez le plan de sol et les ombres.
  4. Utilisez les touches WASD pour parcourir naturellement les espaces.

Rendu de produit

  1. Utilisez le mode d'affichage réaliste.
  2. Réglez soigneusement les propriétés du matériau PBR.
  3. Activez l'IBL avec une carte HDRI d'éclairage de studio.
  4. Ajustez l'exposition pour obtenir la bonne luminosité.
  5. Utilisez le plan de sol avec les reflets activés.
  6. Cadrez la prise de vue avec la projection en perspective.

Dépannages rapides

  • Écran noir : vérifiez si l'objet figure dans l'arbre du modèle ; il peut avoir besoin d'éclairage ou être positionné loin de la caméra.
  • Textures qui clignotent : vérifiez si des UV existent ; sinon, essayez « Générer les UV ».
  • Ombrage étrange : activez « Afficher les normales » pour diagnostiquer des faces inversées ou des problèmes de normales.
  • Sélection impossible : appuyez sur Échap pour annuler tout mode d'affichage spécial actif.
  • Le modèle a disparu : appuyez sur F pour réajuster tous les objets à la vue.
  • Performances lentes : passez en mode Ombré et masquez les objets inutilisés.

Personnalisation

  • Couleur d'arrière-plan : clic droit → « Couleur d'arrière-plan » pour définir une couleur personnalisée de la vue.
  • Thème : allez dans Modifier → Paramètres pour basculer entre les thèmes Clair, Sombre ou Système.
  • Langue : Modifier → Paramètres pour changer la langue de l'interface.
  • Qualité ou performances : utilisez Modifier → Paramètres pour régler le MSAA et le filtrage anisotrope.

Organisation des fichiers

  • Utilisez le menu Récents (Fichier → Récents) pour accéder rapidement à votre travail.
  • Enregistrez les sessions de travail en fichiers .mvf pour conserver les positions de caméra, la visibilité et les réglages.
  • Conservez les fichiers de texture dans le même dossier que vos modèles pour que les chemins soient trouvés automatiquement.
  • Utilisez des noms descriptifs dans l'arbre du modèle (double-clic pour renommer).

En savoir plus

  • Menu Aide : appuyez sur F1 ou allez dans Aide → Aide rapide pour une référence instantanée.
  • Expérimentez : essayez toutes les fonctions avec différents modèles de test pour voir comment elles se comportent.
  • Paramètres : explorez Modifier → Paramètres pour des options cachées supplémentaires.
  • Menus contextuels : faites un clic droit partout pour découvrir des options contextuelles.

Pour conclure

ModelViewer est un outil puissant doté de nombreuses fonctions. La clé de la maîtrise est la pratique :

  • Commencez par la navigation et la sélection de base.
  • Explorez progressivement les modes d'affichage et de caméra.
  • Apprenez la gestion de la visibilité pour les scènes complexes.
  • Expérimentez avec les matériaux et l'éclairage.
  • Découvrez vos propres flux de travail.

Vous avez terminé le tutoriel de base ! Vous avez maintenant les connaissances pour utiliser ModelViewer efficacement au quotidien. Les leçons restantes présentent des fonctions plus avancées et spécialisées.
