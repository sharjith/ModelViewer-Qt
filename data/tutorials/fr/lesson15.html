Leçon 15 : Vues éclatées

Introduction

Les vues éclatées écartent les pièces d'un assemblage le long d'un axe ou radialement à partir d'un point central, afin que vous voyiez comment les composants sont liés sans rien couper ni masquer. C'est une vue échelonnée et non destructive : la géométrie réelle et les transformations de votre modèle ne sont jamais modifiées définitivement.

Ouvrir le panneau Vue éclatée

Étape 1 : Ouvrir le panneau
Ouvrez le panneau Vue éclatée depuis les panneaux de droite.
Capture d'écran: tutorial_15_panel_overview.png (700x500)
Le panneau Vue éclatée avec les commandes d'assemblage, d'ancrage, de mode et de distance

Configurer un éclatement

Étape 1 : Sélectionner l'assemblage
Utilisez « Sélectionner l'assemblage » pour choisir quel groupe d'objets sera éclaté.
Étape 2 : Sélectionner l'ancrage
L'ancrage est la pièce qui reste fixe pendant que tout le reste s'en éloigne. Utilisez « Sélectionner l'ancrage » pour le choisir.
Étape 3 : Choisir le mode d'éclatement
• Auto (radial) : les pièces s'éloignent automatiquement du centre de l'assemblage
• Axe X / Axe Y / Axe Z : les pièces se déplacent le long d'un seul axe du monde
• Vecteur personnalisé : définissez votre propre direction avec les champs de vecteur X, Y, Z
Étape 4 : Stratégie automatique
En mode Auto, choisissez « Selon l'assemblage » (respecte le regroupement des sous-assemblages) ou « Classique » (traite chaque pièce indépendamment).
Capture d'écran: tutorial_15_mode_selection.png (500x350)
Liste déroulante du mode d'éclatement avec les options Auto, Axe et Vecteur personnalisé

Contrôler la distance d'éclatement

Étape 1 : Curseur de distance
Faites glisser le curseur d'éclatement pour contrôler l'écartement des pièces, indiqué en pourcentage.
Capture d'écran: tutorial_15_distance_slider.png (700x400)
Assemblage à 0 %, 50 % et 100 % de distance d'éclatement
Commencez avec un faible pourcentage de distance et augmentez-le progressivement : il est ainsi plus facile de suivre quelle pièce est allée où.

Placement manuel

Pour les assemblages qui nécessitent une disposition réalisée à la main plutôt qu'un éclatement automatique uniforme :

Étape 1 : Démarrer le placement manuel
Sélectionnez les pièces que vous voulez repositionner, puis cliquez sur « Démarrer le placement manuel ».
Étape 2 : Repositionner avec le gizmo de transformation
Le gizmo de transformation à l'écran apparaît sur votre sélection. Faites glisser ses poignées pour déplacer ou pivoter les pièces vers leur pose éclatée échelonnée ; cela ne touche pas à la transformation réelle du modèle.
Étape 3 : Terminer ou effacer
Cliquez sur « Terminer le placement manuel » pour conserver la pose échelonnée, ou sur « Effacer le placement manuel » pour l'abandonner et recommencer.
Capture d'écran: tutorial_15_manual_placement.png (700x450)
Mode de placement manuel avec le gizmo de transformation actif sur une pièce sélectionnée

Capture d'étapes et préréglages

Étape 1 : Capturer
Cliquez sur « Capturer » pour enregistrer la pose éclatée actuelle comme une étape de la séquence. Construisez plusieurs étapes pour créer une révélation échelonnée en plusieurs parties.
Étape 2 : Réorganiser les étapes
Utilisez les flèches haut/bas à côté de la liste des étapes capturées pour modifier l'ordre de lecture.
Étape 3 : Préréglages
Enregistrez une configuration éclatée complète comme préréglage nommé pour passer instantanément d'une disposition éclatée à une autre.
Capture d'écran: tutorial_15_captured_steps.png (500x400)
Liste des étapes d'éclatement capturées avec commandes de réorganisation

Animer l'éclatement

Étape 1 : Mode d'animation
• Animation unique (parallèle) : toutes les étapes capturées s'animent en même temps
• Animation unique (séquentielle) : les étapes se déroulent l'une après l'autre
• Animations séparées : chaque étape devient son propre clip d'animation indépendant
Étape 2 : Retour en boucle
Activez « Retour en boucle » pour que l'animation ramène l'assemblage à sa position d'origine non éclatée à la fin.
Les configurations de vue éclatée, y compris les préréglages et les étapes capturées, sont enregistrées dans votre fichier de session .mvf.
