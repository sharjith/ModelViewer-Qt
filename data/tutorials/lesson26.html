Lesson 26: Mesh Tools

Introduction

Not every model arrives clean: scans have holes and noise, CAD exports have broken topology, and sometimes you need one tidy shell around several parts. ModelViewer has a set of mesh tools for these jobs, built on the CGAL geometry library. This lesson goes through Repair Mesh, Fill Holes, Subdivide Surface, Shrink Wrap and Reconstruct Surface, then the merge and split operations in the right-click menu.

Every tool in the first half of this lesson adds its result as a new mesh and leaves the original untouched, and the whole step is undoable. All five dialogs share one checkbox, Replace previous result, checked by default: each Generate click then undoably deletes the previous click's result first, so you keep at most one result per source mesh. Untick it to let results pile up side by side.

Repair Mesh

Tools → Repair Mesh... runs each mesh in the working list through the repair toolkit: duplicate and degenerate geometry, non-manifold vertices, inconsistent winding and self-intersections. It is defect cleanup only - it never fills holes or forces closure, so an intentionally open panel stays open. A mesh that is already valid is skipped and gets no new node.

Step 1: Open the broken test mesh
Open RepairMeshTest.obj: a mesh built to contain every defect the repair handles, in three separate regions, starting with a bowtie of two triangle fans that share only a vertex.
Step 2: Run the repair
Select the mesh, open Tools → Repair Mesh... and generate. The dialog's status label reports what was fixed. Self-intersection resolution attempts sets how many smoothing and hole-refill rounds to try, and Try smoothing-based resolution too adds a slower strategy.

Fill Holes

Tools → Fill Holes... finds every boundary loop of the meshes in the working list and lets you decide which loops are real defects and which are an intentionally open edge. Only the ticked loops are patched.

Step 1: Open an open cylinder
Open OpenCylinder.obj, which has an open end, and start Tools → Fill Holes....
Step 2: Choose the loops
Click a row of the detected-hole list: that loop is highlighted in orange in the viewport. Tick the ones to patch, set Patch density (how fine the new triangulation is compared with the surrounding mesh) and generate.
Screenshot: tutorial_26_fill_holes.png (700x450)
A detected hole highlighted in orange before it is patched

Subdivide Surface

Tools → Subdivide Surface... smooths a mesh with Loop or Catmull-Clark subdivision. Open TorusTestCoarse.obj, a coarse torus of only 96 triangles, and try:

  • Method: Loop stays triangle-based; Catmull-Clark works with quads internally and is triangulated back afterwards. Both usually look similarly smooth.
  • Iterations: each step roughly quadruples the triangle count, so 1 or 2 is enough to see the effect.
  • Preserve sharp edges (on by default) keeps any edge bent by 30 degrees or more infinitely sharp: a cylinder's flat end caps and a block's corners stay crisp. Turn it off for the classic fully-smooth look, where a cube becomes a rounded blob.
Screenshot: tutorial_26_subdivide.png (700x350)
The coarse torus (left) and its subdivided, smooth result (right)

Shrink Wrap

Tools → Shrink Wrap... combines one or more selected meshes into a single new watertight shell, using alpha wrapping. The inputs need not share a material or even be manifold. Alpha and Offset set how tightly the shell wraps and how far it stands off; Reset to Suggested computes sensible starting values from the selection's bounding box. The original selection is left untouched.

Try it on a few parts of the Forklift or the Skate-Board assembly: a shrink-wrapped shell is a clean, closed stand-in for a complicated assembly, handy for 3D printing or as a simplified collision body.
Screenshot: tutorial_26_shrink_wrap.png (700x420)
A shrink-wrap shell around several parts, next to the original

Reconstruct Surface

Tools → Reconstruct Surface... builds a new triangulated surface from the point positions of selected meshes or point clouds; existing faces are ignored. Sharpness trades smoothness against sharp edges, Boundary Tolerance sets how large a gap the reconstruction may bridge, and Simplify point cloud before reconstruction reveals a Target Spacing that merges closer points first - faster on large or noisy scans, at the cost of fine detail.

Merge, Split and Group (Right-Click Menu)

With meshes selected, the right-click menu in the tree or the viewport offers these operations. All add new mesh nodes and remove the originals, and all can be undone except Select Parent.

OperationWhat it does
Split by ConnectivitySplits each selected mesh into its disconnected pieces, one new mesh per piece; a mesh that is already one piece is left alone.
Merge by AdjacencyGroups the selection into touching clusters (by shared vertex position) and merges each cluster into one mesh; meshes that touch nothing are left alone.
Merge SelectedCombines the whole selection into one new mesh by plain concatenation, touching or not.
Mesh UnionTries a real boolean union of the repaired geometry; if repair or the boolean step fails it falls back to plain concatenation, like Merge Selected.
GroupOnly reorganises the scene tree: creates a Group node and moves the selected meshes into it. No geometry changes.
Select ParentSelects the tree parent of the item you right-clicked - navigation only.
When a touching group or selection has more than one material, Merge by Adjacency, Merge Selected and Mesh Union ask: Keep Materials Separate makes one merge per material, Merge Anyway combines everything and uses the first mesh's material.
