Lezione 2: Aprire i modelli

Introduzione

ModelViewer supporta un'ampia varietà di formati di file 3D. Vediamo come aprire e importare modelli nell'applicazione.

Formati di file supportati

  • Formati mesh: OBJ, STL, PLY, glTF (.gltf, .glb), FBX, 3DS, DAE (Collada), Blender (.blend) e molti altri tramite la libreria Assimp
  • Formati CAD: STEP (.stp, .step), IGES (.igs, .iges), BREP (.brep) tramite la libreria OpenCASCADE
  • Formato nativo: MVF (.mvf): il formato proprio di ModelViewer per salvare scene complete

Metodo 1: dal menu

Il modo standard per aprire i file:

Passaggio 1: Fare clic su File → Apri
Vai al menu File nella barra dei menu e fai clic su Apri, oppure premi Ctrl+O
Schermata: tutorial_02_file_menu.png (300x250)
Il menu File con la voce Apri evidenziata
Passaggio 2: Selezionare il file
Compare una finestra di selezione file. Vai al tuo file di modello 3D e selezionalo.
Schermata: tutorial_02_file_dialog.png (600x400)
La finestra di selezione file con vari formati di file 3D
Passaggio 3: Attendere il caricamento
Il modello viene caricato e una barra di avanzamento mostra lo stato. Per i file grandi può richiedere un momento.
Schermata: tutorial_02_loading_progress.png (500x150)
Barra di avanzamento durante il caricamento di un modello
Puoi annullare il caricamento facendo clic sul pulsante «Annulla caricamento» nella barra di stato.

Metodo 2: Trascina e rilascia

Il modo più rapido per aprire i file:

Passaggio 1: Trovare il file
Trova il file del modello 3D nel tuo gestore di file (Esplora risorse, Finder, Nautilus, ecc.)
Passaggio 2: Trascinare nella finestra
Trascina semplicemente il file e rilascialo in un punto qualsiasi della finestra di ModelViewer.
Schermata: tutorial_02_drag_drop.png (600x400)
Dimostrazione del trascinamento di un file 3D nella finestra di ModelViewer
Puoi trascinare e rilasciare più file contemporaneamente. Ognuno si aprirà in una nuova sessione.

Metodo 3: File recenti

Riapri rapidamente i file con cui hai lavorato di recente:

Passaggio 1: Accedere al menu Recenti
Vai a File → Recenti... per vedere l'elenco dei file aperti di recente.
Passaggio 2: Selezionare il file
Fai clic su un file qualsiasi dell'elenco per aprirlo subito.
Schermata: tutorial_02_recent_files.png (400x300)
Il menu Recenti con l'elenco dei modelli aperti in precedenza

Importare modelli aggiuntivi

Puoi aggiungere modelli a una scena esistente:

Passaggio 1: Usare File → Importa
Fai clic su File → Importa oppure premi Ctrl+I
Passaggio 2: Selezionare i modelli
Scegli uno o più file da aggiungere alla scena corrente.
Passaggio 3: I modelli vengono combinati
I nuovi modelli vengono aggiunti all'albero del modello e compaiono nella vista.
Schermata: tutorial_02_multiple_models.png (700x450)
Vista con più modelli importati e albero del modello che mostra tutti gli elementi
Usa Importa quando vuoi lavorare con più modelli nella stessa scena. Usa Apri quando vuoi ricominciare da zero con un nuovo modello.

Caricamento progressivo

Per i file grandi, ModelViewer usa il caricamento progressivo:

  • Gli oggetti compaiono man mano che vengono caricati
  • Puoi interagire con gli oggetti già caricati
  • La barra di avanzamento mostra il completamento complessivo
  • Puoi annullare in qualsiasi momento
Dopo l'apertura di un file, la vista inquadra automaticamente il modello con «Adatta tutto» così lo vedi per intero. Premi F in qualsiasi momento per adattare tutti gli oggetti alla vista.
