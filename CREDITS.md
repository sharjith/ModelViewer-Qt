## Importer references

- **Autodesk Inventor import research.** Jens M. Plonka's [InventorLoader](https://github.com/jmplonka/InventorLoader) was consulted for the documented import approach. Philippe Lagadec's [olefile 0.47](https://olefile.readthedocs.io/en/latest/License.html) is an external dependency of the research inventory tool. See the [Inventor research provenance](research/inventor/INVENTOR_IMPORT_FEASIBILITY.md#provenance-and-limits).
- **Autodesk Inventor comparison and samples.** [CAD Convert by CNCaddict](https://github.com/CNCaddict/CAD-Convert/tree/a3cbe9f5f41acff810b5006d964d116e805e042b) supplies local Inventor 2026 controls and documents a reader and STEP writer for comparison. No CAD Convert code is incorporated. See the [Inventor research provenance](research/inventor/INVENTOR_IMPORT_FEASIBILITY.md#provenance-and-limits).
- **Inventor compound storage.** Microsoft's public [MS-CFB specification](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-cfb/53989ce4-7b05-4f8d-829b-d08d6148375b), revision 13.0, describes the container used by the native Inventor reader. See the [native reader and verification record](research/inventor/INVENTOR_IMPORT_FEASIBILITY.md#native-compound-file-reader-and-owner-verification).

- **Parasolid XT blend comparison:** monozukuri-ai's parasolid-kit, [commit b91972a](https://github.com/monozukuri-ai/parasolid-kit/tree/b91972a1ff86d8c8b55b07516923f7c35bfedf77). The upstream distribution declares MIT AND Apache-2.0. See the [source comparison and provenance](research/parasolid/PARASOLID_PROVENANCE.md#parasolid-kit-geometry-comparison-17-november-2026).

- **Parasolid XT topology reference:** Open CASCADE Technology 8.0.1, Copyright OPEN CASCADE SAS. The local STEP and IGES translator sources and public B-Rep APIs were consulted for edge, pcurve and wire construction. See the [source comparison and provenance](research/parasolid/PARASOLID_OCCT_TOPOLOGY_COMPARISON.md).
- **3DXML:** cad-in-unity (i2e-haw-hamburg contributors), Apache-2.0, [commit 43a9f0582ecafcdae5bb6f5919c0191467465f86](https://github.com/i2e-haw-hamburg/cad-in-unity/tree/43a9f0582ecafcdae5bb6f5919c0191467465f86), was consulted for XML tessellation concepts. No C# implementation is bundled. See the [consolidated provenance](research/3dxml/3DXML_PROVENANCE.md). This credit does not license third-party CAD samples or imply Dassault endorsement.
- **JT:** Open CASCADE JT-Assistant, Copyright OPEN CASCADE SAS, GPL-2.0-or-later (GPLv3 chosen for the combined work), [commit e859e8c2d809f9d9468e6211eba0052f433978ee](https://github.com/Open-Cascade-SAS/JT-Assistant/commit/e859e8c2d809f9d9468e6211eba0052f433978ee). The [vendored subset](src/ThirdParty/occt-jt/README.md) retains upstream notices and records ModelViewer modifications.
- **JT reference structures/operators:** Copyright 2014 Siemens Product Lifecycle Management Software Inc.; Copyright 2026 Siemens. Used under the published JT reference permissions. See [third-party notices](THIRD_PARTY_NOTICES.md) for the permission sources and limits. No Siemens endorsement or certification is claimed.

- **Assimp glTF transport reference:** the existing Assimp 6.0.4 dependency's glTF2 importer/exporter source was consulted for UV/tangent transport in the original JT role adapter. No source was copied or newly bundled; existing Assimp notices remain with the dependency. See [C2af provenance and hashes](research/jt/JT_TEXTURE_ROLE_VALIDATION.md#evidence-and-provenance).
- **JT line/point research reference:** Johannes Raida's MIT-noticed jCADlib source, retained at [commit 27a12d1970e7684ef369d0a815aee0b7a194b02b](https://github.com/Liamsi/jcadlib/tree/27a12d1970e7684ef369d0a815aee0b7a194b02b), was read for a 9.x record-layout comparison. No Java implementation was incorporated or executed. See [C3 audit provenance and file hashes](research/jt/JT_DISPLAY_PRIMITIVES_AUDIT.md#reference-provenance-and-reproduction).

- **JT component-array hash:** Bob Jenkins' lookup2 word-hash algorithm (1996), described and attributed with a permissive use statement in the retained Siemens JT10 reference, Annex C. Original ModelViewer adapters use it to distinguish a hash-verified production UV transport. See [method and limits](research/jt/JT_PRODUCTION_UV_TRANSPORT.md#method-and-provenance).
- **JT 9.5 independent parser comparison:** JCadLib by Johannes Raida, MIT, inspected at [commit 27a12d1](https://github.com/Liamsi/jcadlib/tree/27a12d1970e7684ef369d0a815aee0b7a194b02b) as an independent comparison for raw exponent/mantissa colour and UV reconstruction. No Java source is bundled or copied. See [method and limits](research/jt/JT_95_PRODUCTION_TEXTURE_PROFILE.md#method-provenance-and-limits).
