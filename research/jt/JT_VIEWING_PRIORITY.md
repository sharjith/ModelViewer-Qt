# Core viewing priority and paused C2 backlog

24 October 2026, `feature/JT-importer`. Owner-directed priority change after accepted C2ag `dea4c25`. This is a planning/continuation record, not new implementation or test acceptance.

## Owner decision

Pause further C2 appearance expansion, preserve the delivered implementation and return to its residual work later. The purpose of ModelViewer is viewing: broad import fidelity is useful even when the material editor cannot author the original construction. Exhaustive authoring is not a requirement of this work. The current priority is generic viewing capabilities rather than successively narrower texture combinations.

The accepted C2 boundary remains C2ag, including `fe6d623` (bounded normal/post-lit roles), `7a18b9d` (shared unlit corrections) and `dea4c25` (normal mip filtering). A pause does not declare C2 complete, remove its requirements, or revert accepted behaviour. Historical gate and failure records remain intact.

## Retained return checklist

The authoritative seven-area backlog is [remaining C2 scope](JT_C2_REMAINING_SCOPE.md). It retains:

1. Broader combiners, vertex-colour interactions and blending/inheritance semantics.
2. Independent texture stages with separate coordinates, transforms, wrapping and filtering.
3. Remaining image formats, border profiles and derivative-sensitive clamp cases.
4. General projective, view-dependent and higher-dimensional mapping.
5. Broader normal/bump/gloss/environment/light-map and pre-/post-lit roles.
6. Qualified evidence for JT8 authored textures.
7. Authentic exporter, native-suite/backend and broader family/export qualification.

[Batch 1 comeback](JT_BATCH1_COMEBACK.md) remains the detailed prerequisite list for deferred combiners/stages. [C2ad](JT_BORDER_BATCH_VALIDATION.md), [C2ae](JT_HOMOGENEOUS_MAPPING_VALIDATION.md), [C2af](JT_TEXTURE_ROLE_VALIDATION.md) and [C2ag](JT_NORMAL_MIP_VALIDATION.md) retain the accepted subsets and explicit limits. No reference/evidence gap is closed by this priority decision. No new texture-expansion gate should be selected automatically; returning to the backlog requires owner prioritization. Record real-model appearance failures for that discussion. Preserve accepted appearance coverage during core-viewing changes.

## Immediate direction: C3 and generic viewing essentials

Begin with a read-only coverage/evidence audit for C3 line/wire and point representations, then implement a coherent bounded gate where source layouts are established. Actual line/curve entities are distinct from drawing triangle-mesh edges. Unknown required records must not be silently skipped or mislabeled as an empty model. Missing production/reference evidence must be recorded and requested before a cause-specific compatibility claim.

| Priority | Viewing outcome and acceptance focus |
| --- | --- |
| First: C3 display content | Read applicable line/wire and point content as actual primitives, alongside triangles; correct topology, colour, bounds, transforms/units, selection/visibility and application export where representable |
| Cross-cutting throughout | Preserve assembly hierarchy, shared-instance identity, existing geometry/appearance and exact/tessellation fallback; bounded resource use, cancellation and useful unsupported/failed-content diagnostics |
| Then: C4 useful information | Basic typed properties, identity and units in the viewer; prioritize common information before wider PMI/annotation variants, with preservation versus rendering clearly separated |
| Then: C5 runtime detail | Retain and switch qualified LOD alternatives while maintaining selection, identity, resource sharing and bounds without duplicate display |

These are priorities for auditing existing coverage and filling gaps, not claims that all listed behaviour is absent or that complete C3/C4/C5 is one build. Group related cases into meaningful owner checkpoints. The owner continues to build/test; native-suite and backend acceptance must be reported separately from visual acceptance. Do not infer a pass from a request to continue.

Exact geometry C6 and consolidation C7 remain on the [feature plan](JT_FEATURE_COMPLETION_PLAN.md). C1 residuals also remain open; address a concrete dependency when a priority viewing feature needs it. The paused appearance backlog is not a prerequisite for every subsequent stage. JT10.11 and additional revisions remain deferred under the existing enabled-version policy.
