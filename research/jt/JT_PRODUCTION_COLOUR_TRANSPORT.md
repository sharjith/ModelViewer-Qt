# Production modern lossless colour transport

14 November 2026, `dev`. This is a production compatibility gate for an
owner-supplied JT 10.9 file, identified here as **C109-A**. Its original name,
path, geometry and derived payload bytes remain private and untracked.

## Failure and evidence

The application rejected the first display alternative with `JT vertex colour
component is outside [0,1]`. C109-A is little-endian JT 10.9, 56,174,906 bytes,
SHA-256 `1dc7e9661f2a0ee37814242ea00cff820cc9d3959a07b70d794d635fdd124016`.
It contains 53 stored shape-LOD segments and no JT or XT B-Rep fallback.

A read-only partial payload audit located seventeen lossless RGB colour
collections. For every collection, the chained lookup2 word hash of the raw
IEEE component arrays exactly equals the stored colour hash. Every raw value is
finite and within `[0,1]`. Applying the reader's existing Lag1 predictor changes
the hash in fifteen nonconstant collections and produces out-of-domain values;
two constant collections happen to be unchanged under either interpretation.
This establishes a transport-selection error, not malformed source colours.

The same profile was previously observed and owner-accepted for modern binary
UV arrays. A checksum match is not a cryptographic authenticity guarantee, but
it is format evidence over the complete ordered component arrays. The decoder
must not select a transport merely because trial values look finite.

## Bounded correction

For modern unquantized vertex colours, the original reader now decodes integer
packets without prediction first and computes the chained component-array hash.
A complete raw-hash match selects the raw IEEE words. Otherwise the reader
retains its established Lag1 interpretation. Only after selection are values
required to be finite and within `[0,1]`.

The explicit raw mode already used by qualified JT 10 polyline and point-set
records remains raw. Modern packed quantized colours and the distinct JT 9.x
exponent/mantissa and quantized transports are unchanged. No clamping, colour
discard, filename/version heuristic or renderer change is introduced.

Original regression vectors cover raw/hash and Lag1/hash RGB and RGBA, both
byte orders, plus hash-matching NaN, negative and above-one raw values that must
still be rejected. Existing colour tests retain truncation, count, component,
quantized, JT 9.x, cancellation and allocation coverage.

## Reproduction and owner gate

The ignored read-only reports are
`out/jt-research/c4-colour-candidate.structure.json` and
`out/jt-research/c4-colour-candidate.transport.json`. They contain private-file
working context and are not tracked. The structural inventory is regenerated by:

```text
python -B tools/jt/inspect_jt_structure.py <private-C109-A.jt> --output out/jt-research/c4-colour-candidate.structure.json
```

The isolated Release codec build, full Release `ModelViewer` target and
registered test passed on 14 November 2026. The authentic probe also passed
with 53 meshes, 198,205 vertices,
226,698 triangles, 17 colour meshes, 36 UV meshes, no B-Rep fallback and all
geometry, normals, indices, transforms and colour components validated. The
probe reported unsupported PMI Manager version 4 metadata and one unqualified
texture mapping independently of this colour transport gate.

The exact verification commands, after loading the Visual Studio x64
environment and placing the vcpkg and Qt runtime directories on `PATH`, were:

```text
cmake --build out/jt102-build --target jt_tests jt_probe --parallel 1
ctest --test-dir out/jt102-build -R "^jt_codec_tests$" --output-on-failure
out/jt102-build/jt_probe <private-C109-A.jt> --validate
cmake --build out/build/ninja_release_vcpkg --target ModelViewer --parallel 4
```

The owner application gate is to open unchanged C109-A, compare geometry and
vertex colours with a trusted viewer in ADS and PBR, check fit and selection,
and reopen a previously accepted coloured JT regression. A different first
failure is new evidence, not permission to suppress required display content.

Reference, Version 10.0, Revision B* sections 13.1.6 and Annex C. Retained PDF
